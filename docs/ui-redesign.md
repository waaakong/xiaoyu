# 小鱼 UI 重构 · 2026-11-08

## 目标与设计

在现有原生 JavaScript / WebView2 架构上，统一整个工作台的布局、功能文案、深浅主题与动效。参考 macOS 分栏和 iOS 材质层级：导航、工具栏与弹窗使用磨砂玻璃；长文本、表单和数据表使用更实的阅读层。保留原有业务处理器、授权及数据隔离。

## 实现范围

- `ui/liquid.css`：共享材质、排版、控件、卡片、设置、表格、窄窗口与无障碍样式。
- `ui/shell-ui.js`：导航分组、总览、快捷入口和窄窗口导航；沿用原 DOM 和业务事件。
- `ui/workspace-copy.js`：各功能的导航名称、标题与静态说明；连接状态和操作结果由业务模块提供。
- `ui/workspace-motion.js`：统一弹窗入场与中断清理；页面切换继续由 page-navigation 管理。
- 外观背景随深浅主题变化，自选图片与本地保存方式沿用。
- 首次配置、连接设置、记忆、语音和日记相关文案统一；未配置微信时展示朋友圈接入空状态。
- `src/gui.js` 只增加本地静态资源映射。

## 执行和验收

1. 备份 UI 与 GUI 文件，在修改前记录测试基线。
2. 安装锁定依赖并实现共享样式、导航、文案与动效。
3. 在临时目录运行隔离的 GUI，不启动模型连接和消息服务。
4. 检查全部 31 个导航入口、桌面与窄窗口、深浅主题、弹窗、下拉框、草稿和减少动态效果。
5. 执行 UI 相关测试和完整 Node 回归，区分迁移环境的原有失败。

## 动效约定

页面切换用于衔接内容变化，GSAP `power3.out`、200ms、位移 6px；弹窗用于空间层级，220ms、缩放 0.98→1。快速重复切换会取消上一段动画并清理样式。按钮按下用 CSS 140ms，键盘导航即时提交，减少动态效果时移除位移和缩放。无持续背景动画、无自动滚动。

## 开发注意

GUI 启动时快照所有 UI 文件，修改后须重启后端才能看到同一版本的全部资源。浏览器检查使用系统 Edge 与已有 Playwright；本会话未提供 Browser 插件。运行真实 QQ、微信、语音及发布功能仍需迁移后单独配置和验收。

## 本次验证结果

- UI 相关 Node 测试 14 项全部通过，包含新增静态资源路由的实际 HTTP 检查。
- 系统 Edge、1440×1000 与 390×844：31 个导航入口均可打开；168 项检查通过，页面脚本和控制台无错误。覆盖深浅主题、弹窗、下拉框、草稿保留、窄窗口导航及焦点归还、取消外观还原、系统减少动态效果。
- 完整 Node 回归：554 项通过、2 项失败、4 项跳过。失败为迁移环境尚未安装 `@deepseek-ai/dsh-llm`，以及缺少原生面板编译需要的 WebView2 DLL；两者在 UI 改动前的基线中已失败。
- 未启动真实 QQ / 微信消息通道、模型生成、语音或对外发布。桌面原生宿主构建需后续准备 WebView2 SDK 后验证。

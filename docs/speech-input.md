# 本地语音识别与语气线索

0.16.0 将语音输入与 GPT-SoVITS 语音输出分开配置。输入使用官方 SenseVoiceSmall 量化 ONNX 模型、CPU 推理，无需 CUDA、PyTorch 或云端语音 API。原始音频仅在本机解码；转写文字会进入所选聊天的 Codex 模型及本机聊天历史，遵循原有记忆设置。

## 准备与开启

1. 在“依赖”页点击“准备语音识别”。会创建独立的 `data/speech-env`，从官方模型仓库下载约230MiB量化权重及辅助文件，并校验固定 SHA-256。依赖下载源沿用所选 PyPI/阿里云设置；模型始终来自官方 ModelScope 仓库。可取消和重试，不更改 AstrBot 环境。
2. 在“QQ接入 → 本地语音识别”运行公开音频自检或选择本机音频测试，不调用聊天模型、不发QQ。
3. 开启“允许接收语音”，再在对应联系人的“接收语音”设置中勾选识别。新安装全局和各聊天默认关闭，旧聊天授权不变。
4. “参考语气线索”可分别全局和逐聊天关闭。GPT-SoVITS 回复模式仍是独立设置。

支持QQ SILK、WAV、MP3、OGG、FLAC、M4A和AMR，单条最多60秒、10MB。首次加载耗时高于后续识别；闲置5分钟释放模型。这里只读取收到的QQ语音，不监听麦克风。

## 群触发与安全

默认需真正@角色、引用本工具已确认的回复、成员续聊或同条附带文字唤醒。普通群语音不会下载或识别。可单独开启“从群语音内识别唤醒词”：这会先本地转写授权群的语音，只有命中唤醒词才进入聊天模型。随机自然接话不会直接唤醒语音。

转写后的斜线命令不会自动执行。文字“/取消”可中断待处理语音；关闭授权、暂停聊天、QQ断线也会取消。识别与后续文字按聊天顺序进入队列，普通流程和AstrBot增强流程共用转写结果，避免重复识别或回复。

通过OneBot `get_record`优先取得WAV/base64，失败时使用原语音。只允许QQ官方HTTPS媒体地址，禁止重定向；本地路径须由协议动作返回且位于已知协议缓存内。下载后的小鱼临时副本处理结束即删除；意外崩溃遗留的自有临时目录在下次启动时清理（超过1小时）；QQ和协议端自身缓存仍由其管理。不会通过此功能上传音频给第三方ASR。

## 情绪能力的实际范围

SenseVoice输出语言、粗略情绪和声音事件标签。小鱼将其作为“语气线索”，并明确告知模型：可能有误，不能代表真实心情、不能作为用户原话或长期记忆证据。没有明确标签时返回“不确定”，不生成置信百分比。聊天原文以“语音转写”标记，语气字段独立显示。识别受音质、口音、背景音乐与说话方式影响；重要内容应向本人核实。
